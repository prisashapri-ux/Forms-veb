# Форма в браузере

Веб-версия «Формы»: дневник тренировок и состав тела по отчётам InBody из DDX Fitness. Работает в Safari на iPhone без установки через Xcode, ставится на экран «Домой» и открывается без интернета.

Сервера нет. Все данные хранятся в браузере (IndexedDB) на том устройстве, где ими пользуются. Переносить данные можно резервной копией JSON, она совместима с iOS-приложением «Форма» в обе стороны.

## Что умеет

- **Тело.** Импорт PDF-отчёта InBody: разбор прямо в браузере через pdf.js, без отправки файла куда-либо. Условия замера, изменения с пометкой погрешности, тренд за месяц, график с коридором нормы, шкалы норм, сегменты, обмен и цели.
- **Дневник.** Тренировки, подходы, разминочные, подсказка «Сегодня» по двойной прогрессии, таймер отдыха, замена и перестановка упражнений, готовые программы, справочник с техникой и своими заметками.
- **Аналитика.** Советы по офлайн-правилам, тренировки, тоннаж и подходы со сравнением периодов, тоннаж по неделям, подходы по группам, календарь, прогресс по упражнениям, тело рядом с тоннажем.
- **Питание.** Белок и калории за день от нормы InBody и цели, быстрые кнопки.

## Разработка

```
npm install
npm test        # тесты логики и (при наличии примера отчёта) разбора PDF
npm run build   # собирает сайт в dist/
```

`dist/` можно открыть любым статическим сервером, например `python3 -m http.server -d dist`.
